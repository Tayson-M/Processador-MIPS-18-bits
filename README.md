# Processador-MIPS-18-bits
Desenvolvimento de um processador do tipo MIPS de 18 bits para atividade N1 do 2°Bimestre de Arquitetura de Computadores

#Como usar
Faça o download do Logisim Evolution (https://github.com/logisim-evolution/logisim-evolution)
Faça o clone ou download desse repositorio
Abra o arquivo Processador.circ no Logisim Evolution
Carregue a memoria ROM com as instruções que desejar em hexadecimal
Habilite a simulação e os pulsos de clock
